# 90-Day Execution Plan

## Days 0-30 - Prove pain and foundations
- Interview 20-30 platform/engineering leaders.
- Secure 3-5 design partners.
- Freeze Work V1 and Worker Protocol draft.
- Implement local Linux worker.
- Implement durable Work/DAG persistence.
- Establish benchmark corpus and baseline.
- Complete initial threat model.
- Resolve working brand/domain/trademark direction.

## Days 31-60 - Prove execution
- Worker registration, heartbeat, leases, cancellation.
- Scheduler with capability constraints.
- Worker-loss recovery.
- Log streaming and artifacts.
- GitHub webhook/check integration.
- First content-addressed fingerprints.
- Cold/warm/affected benchmark suite.
- Minimal web execution view.

## Days 61-90 - Prove customer value
- Run design-partner pilots.
- Add BYOC worker pools.
- Measure time-to-green, compute and cost.
- Make first successful Work consistently <5 minutes from onboarding.
- Add audit baseline and scoped secrets.
- External security review of critical path.
- Decide paid-beta packaging from observed value.
