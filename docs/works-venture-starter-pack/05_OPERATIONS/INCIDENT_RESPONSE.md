# Incident Response

## Severity
SEV0: cross-tenant/security integrity incident  
SEV1: widespread execution outage/data-integrity risk  
SEV2: major degraded execution or integration  
SEV3: limited feature degradation

## Mandatory incident artifacts
- incident ID
- start/detection/mitigation timestamps
- affected tenants
- Work IDs
- root cause
- customer impact
- remediation
- prevention actions
- evidence/log retention

Security incidents follow a separate disclosure and credential-revocation path.
