# North Star & Metrics

## North Star
**Verified Work Throughput**

Verified outcomes divided by:
- wall-clock latency;
- compute cost;
- required human attention.

## Core metrics
- Time to First Work
- Time to Green (P50/P95)
- Critical-path duration
- Queue wait
- CPU/GPU minutes executed
- Compute minutes avoided
- Cache hit rate
- Artifact transfer time
- Infrastructure failure recovery rate
- Manual interventions per 100 Works
- Cost per verified Work
- Work success rate
- Worker utilization
- Scheduler assignment latency
- Evidence completeness rate

## Guardrails
Never improve speed by silently reducing required verification.
