# Competitive Landscape - August 2026

## GitHub Actions
Incumbent distribution and repository integration. Current published hosted-runner pricing includes $0.006/min for standard 2-core x64 Linux and $0.062/min for standard macOS, with job usage rounded to whole minutes.

## Buildkite
Strong architectural analogue: hosted control plane, self-hosted agents and dynamic pipelines. Buildkite also supports incremental GitHub Actions migration and, in August 2026, expanded its compatibility preview to reusable workflows, Docker actions and service containers.

## Nx Cloud
Strongest task-intelligence analogue. Nx positions its CI as task-based rather than VM-based, with affected execution, remote caching, distributed agents, flaky-task handling and self-healing CI. Nx Agents use dependency information and historical runtimes for task allocation.

## Depot
Strong wedge competitor. Depot documents a one-line runner-label migration for GitHub Actions, advertises up to 3x faster runners and 10x faster caching, and publishes per-minute runner pricing.

## Strategic conclusion
WORKS cannot credibly claim remote cache, BYOC, dynamic pipelines, affected execution, faster runners or AI remediation as unique. The venture must differentiate through durable Work, execution truth, evidence, heterogeneous worker/agent execution and a cross-work optimization flywheel.
