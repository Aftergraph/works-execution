# Security Baseline

- TLS everywhere.
- Unique revocable worker identities.
- Short-lived Work-scoped credentials.
- Encrypted secret store.
- Secret masking in logs.
- Tenant-isolated cache/artifact namespaces.
- RBAC.
- Immutable audit stream.
- Artifact/evidence integrity hashes.
- Signed worker releases/update metadata.
- Explicit worker trust classes.
- Fork-aware secret policies.
- Least privilege by default.
