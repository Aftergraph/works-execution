# Open Source Strategy

## Candidate open components
- worker protocol/schema
- CLI
- worker runtime or a constrained community worker
- SDKs
- local developer mode

## Keep commercial initially
- hosted control plane
- advanced scheduler intelligence
- organization-wide evidence analytics
- enterprise policy/governance
- managed compute orchestration

## Principle
Open source should increase trust, integrations and distribution without donating the entire commercial control plane before product-market fit.
