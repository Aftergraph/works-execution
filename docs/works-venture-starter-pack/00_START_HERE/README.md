# WORKS - Venture Starter Pack V1

**Category:** Autonomous Software Execution Infrastructure  
**Mission:** Minimize the time, compute, and human intervention required to turn software intent into a verified result.

## What this pack contains
This is the operating documentation for starting WORKS as a standalone venture. It includes product, architecture, engineering, security, operations, go-to-market, business, research, templates, ADRs, examples, and company-formation checklists.

## Product boundary
WORKS is not an AVC subsystem. AVC may become a design partner or customer, but WORKS must remain repository-host-neutral, runtime-neutral, and independently commercializable.

## Initial wedge
1. Connect a GitHub repository.
2. Run existing GitHub Actions-compatible workloads on WORKS workers.
3. Show measurable runtime/cost/reliability value.
4. Migrate selected workloads to native Work Graphs.
5. Expand into evidence-driven and agent-native execution.

## First proof
A real repository must demonstrate:
- onboarding in minutes;
- execution on a WORKS worker;
- durable state;
- worker-loss recovery;
- artifact/evidence preservation;
- measurable baseline comparison.
