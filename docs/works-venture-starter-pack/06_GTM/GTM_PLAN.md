# Go-To-Market Plan

## Initial ICP
Engineering organizations with:
- 10-200 developers
- GitHub-centric development
- meaningful CI spend
- >10 minute pipelines
- monorepos/large repos or Docker-heavy builds
- platform/DevOps ownership
- increasing coding-agent usage

## Wedge
Drop-in compatible execution first. Native Work Graph second.

## Land and expand
1. Replace selected GitHub-hosted execution.
2. Prove speed/cost/reliability.
3. Add organization cache and BYOC.
4. Move expensive pipelines to native Work.
5. Add governance/evidence.
6. Add agent execution.

## Sales proof
Sell measured reduction in cost/time per verified change, not generic AI claims.
